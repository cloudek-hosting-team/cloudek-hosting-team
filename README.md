# Cloudek

Practical tools and guides for people who run Microsoft 365, Entra ID, email and infrastructure.

We are a small cloud and hosting services company. This page links to the things we publish openly. It is not a product catalogue, and nothing here is a certification or an audit.

## What we publish

- **Free IT admin tools**: subnet and DNS helpers, email checks, Microsoft 365 licence tools, log and token helpers. Most run in your browser. https://www.cloudekhosting.com/tools.html
- **Email Health Check**: scores a domain for SPF, DKIM, DMARC, MX and more using public DNS only. https://www.cloudekhosting.com/tools/email-health-check.html
- **Conditional Access Policy Reviewer**: reviews exported Entra Conditional Access JSON for missing MFA, legacy authentication, risky exclusions and report-only policies. Runs in your browser. https://www.cloudekhosting.com/tools/conditional-access-policy-reviewer.html
- **Email authentication study (November 2026)**: SPF, DKIM and DMARC records for 500 well-known domains, aggregates only, with method and limits. https://www.cloudekhosting.com/email-authentication-report-2026.html
- **Guides**: practical walkthroughs for identity, email security and Microsoft 365 operations, with Microsoft Learn sources and licence notes. https://www.cloudekhosting.com/blog.html

## OpsPilot

OpsPilot is our read-only Microsoft 365 review workspace. It reads and reports; it never changes a tenant.

- **Sixteen read-only reviews** with plain-English findings, the evidence behind each and an A to F grade: https://www.cloudekhosting.com/opspilot-reports.html
- **Interactive demo** with sample data for a fictional organisation. Nothing to install, no tenant connected: https://www.cloudekhosting.com/opspilot-customer-reports.html?demo=1
- **Free trial**: by invitation, 30 days, one organisation of up to 250 users, read-only. Ask by email: info@cloudekhosting.com

Where a check needs a licence you do not have, OpsPilot says "Not checked: needs ..." instead of showing a pass.
